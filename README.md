# NetMind

AI-Powered Network Troubleshooting Agent

NetMind is an intelligent agent that investigates network faults,
analyzes diagnostic evidence, identifies probable root causes, and
recommends troubleshooting actions.

## Features
- Ping and connectivity diagnostics
- DNS analysis
- Traceroute diagnostics
- AI-driven troubleshooting with Gemini
- Offline rule-based fallback
- Web-based dashboard

## Tech Stack
- Python
- Flask
- Google Gemini (google-genai)
- Network diagnostic tools
- GitHub
